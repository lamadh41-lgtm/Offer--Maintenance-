# نظام الصيانة المتقدم · Toyota Maintenance

نظام أسعار صيانة تويوتا مع خصومات خاصة — واجهة عربية RTL.

## الملفات (كلها في الجذر)

```
index.html
styles.css
data.js
app.js
sounds.js
utils.js
README.md
```

## التشغيل

افتح `index.html` في المتصفح (يحتاج إنترنت مرة واحدة لتحميل مكتبة SheetJS للتصدير).

- للتطوير بدون فحص الشبكة: `?dev=1`
- أو افتح الملف مباشرة `file://`

## التصدير

زر **تصدير مقايسة** يُنشئ ملف Excel بنفس نموذج مقايسة البرجسى:
- يملأ نوع السيارة والموديل والطراز وتاريخ التصدير
- في بند الميكانيكا يكتب: **صيانة** + نوع الصيانة المختار
- يضع قطع الغيار والكميات والإجماليات + ضريبة 14%

## كلمة المرور (حالة خاصة)

`ساعة(1-12) + يوم + شهر + سنة`
